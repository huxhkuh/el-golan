# נגריית אל גולן

אתר בעברית עבור נגריית אל גולן בירושלים, בעיצוב כהה וחם עם גלריית פרויקטים, סינון לפי תחום, הגדלת תמונות ויצירת קשר.

כל 19 תמונות הפרויקטים הן הקבצים המקוריים מתוך האתר הקיים, ללא שינוי בתוכן התמונות. מקורות הקבצים מתועדים ב־ASSET_SOURCES.json.

## הרצה מקומית

דרוש Node.js 22 ומעלה.

```bash
npm ci
npm run dev
```

## בנייה ובדיקות

```bash
npm run build
npm run test:sites
```

## פריסה

אפשר לחבר את המאגר ל־Cloudflare Pages, Netlify או שירות אירוח סטטי אחר.

- פקודת בנייה: `npm run build`
- תיקיית הפלט לאירוח סטטי: `dist/client`
- משתני סביבה וסודות: לא נדרשים לאתר הנוכחי.

האתר אינו כולל שרת לשליחת טפסים: כפתורי יצירת הקשר פותחים חיוג או תוכנת מייל.

## עריכה

- תוכן, כותרות, גלריה וקישורי קשר: `src/App.jsx`
- עיצוב והתאמה לנייד: `src/styles.css`
- תמונות ופונט: `public/assets`

שמירת הקוד ב־GitHub אינה מחברת אוטומטית את הדומיין הקיים או משנה את הגדרות האחסון שלו.

## GitHub Pages

GitHub Pages מוגדר לפרסום מתוך ענף `main`, בתיקיית השורש. לכן המאגר כולל גם גרסה בנויה: `index.html` ו־`assets/`.

קובץ ה־HTML לעריכת קוד המקור הוא `app.html`. אין לערוך ידנית את `index.html` או את חבילות ה־JS/CSS שב־`assets/`.

לאחר שינוי הקוד, מריצים:

```bash
npm run build:pages
npm run test:pages
npm run test:sites
```

יש לשמור ב־commit גם את קבצי הפרסום המעודכנים. GitHub Pages מפרסם אותם אוטומטית בעקבות העדכון לענף `main`. נתיבי הקבצים יחסיים, ולכן האתר מתאים גם לכתובת `/el-golan/` וגם לדומיין נפרד.
